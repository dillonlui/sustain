# Sustain 1.0.2 — Intel Mac preview

Sustain 1.0.2 packages the app as Universal 2, so it runs natively on both
Apple-silicon and Intel Macs running macOS 14 or newer.

The automated test suite and Universal 2 package validation run on both
Apple-silicon and Intel macOS CI runners. Intel audio hardware has not yet been
validated on a physical Mac, so Intel support remains a preview. Please report
your Mac model, macOS version, and any launch or audio issues.

## Intel test checklist

- Install and launch Sustain normally from the disk image.
- Run System Check and play pads, click, and spoken count-off.
- Start, stop, and transition between songs.
- Select an external audio output or interface, if available.
- Sleep and wake the Mac, then confirm playback and routing recover correctly.
- Quit and reopen the app and confirm the library is preserved.
- Run pads and click continuously for at least 30 minutes.

Automated CI cannot cover a Finder install, real audio devices, or sleep/wake
behavior on physical Intel hardware. Complete this checklist on at least one
supported Intel Mac before removing the preview label.
