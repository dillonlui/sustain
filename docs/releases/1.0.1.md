# Sustain 1.0.1 — Intel Mac preview

This release adds preliminary support for Intel Macs running macOS 14 or newer.
Sustain is now distributed as a Universal 2 app that runs natively on both Intel
and Apple-silicon Macs.

The Intel build compiles successfully and passes package validation, but it has
not yet been tested on physical Intel hardware. Intel Mac users are invited to
report their Mac model, macOS version, and any launch or audio issues.

## Intel test checklist

- Install and launch Sustain normally from the disk image.
- Run System Check and play pads, click, and spoken count-off.
- Start, stop, and transition between songs.
- Select an external audio output or interface, if available.
- Quit and reopen the app and confirm the library is preserved.
- Run pads and click continuously for at least 30 minutes.
