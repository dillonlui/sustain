## Staging update walkthrough

Record the 1.1.1/build 4 → 2.0.0/build 5 path, staging appcast URL,
notarization submission IDs, ZIP and DMG SHA-256 hashes, and the Mac and macOS
version used. Install the lower build in `/Applications` and confirm:

Use a disposable macOS test account. Sparkle 2.9.6 allows the signed 1.1.1
bundle's `SUFeedURL` to be overridden through that account's `com.sustain.app`
user defaults, so it can read the staging feed without editing or re-signing the
public app. Verify the override is active before checking, and delete it when
the rehearsal ends. The production feed and everyday user data must stay
untouched during this test.

After the protected rehearsal workflow publishes the staging appcast, run these
commands in the disposable account with Sustain closed:

```sh
defaults write com.sustain.app SUFeedURL \
  'https://raw.githubusercontent.com/dillonlui/sustain/staging-updates/appcast.xml'
defaults read com.sustain.app SUFeedURL
```

After the rehearsal, close Sustain and run
`defaults delete com.sustain.app SUFeedURL`. Confirm the setting is absent
before using that account for normal update checks.
