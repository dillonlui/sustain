Generated with the built-in imagegen tool as visual explorations. The existing `docs/brand concept mockups.png` was supplied as a **style and identity reference** for the palette and one-stroke wave; these screens are new concepts, not edits to the app or source assets.

These images show mood, hierarchy, and component treatment. Generated text and navigation are illustrative and may differ from the actual product. In particular, do not treat added slogans, controls, or output names as approved requirements. The level bars represent **configured volume**, not measured audio signal. Preserve actual product terminology, routes, keyboard interactions, accessibility, and current Live behavior when turning a concept into UI.
